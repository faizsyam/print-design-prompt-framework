# Visual Identity & Style Synthesis

*Used in Phase 2 of `SKILL.md`.*

This reference guide establishes the principles and systematic methods for selecting design movements, defining visual form language, orchestrating color systems, and architecting standalone brand marks without relying on static terminology banks or lookup tables.

---

## 1. Visual Movement & Style Selection Strategy

Rather than using generic aesthetic labels, visual style selection requires identifying an established design movement, visual tradition, or structural style defined by concrete, observable traits.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     DESIGN MOVEMENT & TRADITION                         │
│        (named, specific, and defined by concrete observable traits)     │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
        ┌────────────────────────────┼────────────────────────────┐
        │                            │                            │
┌───────┴───────────────┐  ┌─────────┴───────────────┐  ┌─────────┴───────────────┐
│     FORM LANGUAGE     │  │  LINEWORK & RENDERING   │  │   SURFACE & TEXTURE     │
│ Shape vocabulary and  │  │ Line quality and depth  │  │ Substrate and print     │
│ boundary behavior     │  │ technique               │  │ character               │
└───────────────────────┘  └─────────────────────────┘  └─────────────────────────┘
```

### 1. Evaluating Design Movements
The selectable range is the full breadth of design history and contemporary practice: named movements, regional and vernacular traditions, craft and print techniques, period styles, and coherent hybrids or invented directions. No part of that range is reserved for a type of business. Derive the choice from the intersection of the brand's character and positioning, the communication objective, the audience, the medium's reading distance and exposure, and the physical environment.
* **Diverge before converging:** Consider several candidates that differ meaningfully before settling. Do not default to the most conventional pairing of business type and style.
* **Test each candidate:** It must fit the brief, be distinctive to this brand, remain effective at the medium's reading distances, and be specifiable in concrete, observable traits.
* **Combine only with a dominant voice:** A hybrid is valid when the result is coherent and one tradition clearly leads.

### 2. Defining Observable Visual Characteristics
Once a movement is selected, articulate its execution through four concrete visual pillars:
1. **Form Language & Shape Vocabulary:** Specify boundary behaviors and the shape logic that carries the concept.
2. **Linework & Edge Behavior:** Define line quality, weight, and stroke behavior.
3. **Rendering & Shading Technique:** Define how depth and surface are rendered, including whether depth is present at all.
4. **Texture & Print Material Fidelity:** Define paper and print characteristics that suit the substrate and the reading distance.

## 2. Color System Architecture (60-30-10 Rule)

Color systems in print design must enforce structural readability, psychological alignment, and environmental contrast. Apply the **60-30-10 structural color ratio** as the baseline proportion hierarchy. Adjust the proportions, or the number of color roles, when the concept demands it, provided the accent remains the smallest and highest-priority role:

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       DOMINANT TONE (60%)                               |
|        Backgrounds, Large Surface Containers, Overall Base Atmosphere   |
|                                                                         |
|               +-----------------------------------------+               |
|               |                                         |               |
|               |       SECONDARY STRUCTURE (30%)         |               |
|               |  Text Blocks, Major Grid Lines, Framing |               |
|               |                                         |               |
|               |         +-----------------------+       |               |
|               |         | ACCENT / ACTION (10%) |       |               |
|               |         | Badges, CTAs, Hooks   |       |               |
|               |         +-----------------------+       |               |
|               +-----------------------------------------+               |
+-------------------------------------------------------------------------+
```

### 1. Structural Palette Allocation
* **Dominant Tone (60%):** Establishes the primary visual substrate and atmospheric baseline. Provides high contrast against both secondary copy elements and external ambient environments.
* **Secondary Structural Tone (30%):** Defines organizational grid containers, major visual framing, body typography, and structural graphic elements.
* **Accent / Action Tone (10%):** High-chroma, high-visibility color reserved strictly for the elements the Attention Hierarchy (`01`) ranks highest, such as price hooks, primary callouts, and key brand accents. Accent follows priority, not a content category. Never dilute accent colors by using them in large background areas.

### 2. Contrast & Environmental Logic
* **Color Relationships:** Choose temperature, value, and saturation relationships for psychological alignment with the brand and for contrast against the environment. Balance opposing qualities so the palette carries both the energy and the stability the concept requires.
* **Print Chromaticity:** Account for substrate physics. Colors conceived in light must be translated into saturated equivalents that the print process can actually achieve.

## 3. Brand Mark Strategy & Visual Autonomy

The primary logo mark is the central anchor of brand identity. It must maintain **structural autonomy**—standing apart as a distinct visual asset while harmonizing with the overall print composition.

### 1. Autonomy & Independence Principle
* **Context Isolation:** The main logo mark must never depend on product illustrations, background photography, or seasonal props to be recognizable.
* **Iconographic Independence:** Avoid literal visual duplication between the logo and specific product offerings. The logo represents the *institution*, not a single product variant.

### 2. Structural Mark Architectures
Derive the logo lockup from three decisions, in light of brand character and the medium's reading distance:
* **Enclosure:** Whether the mark is contained within a boundary or open, judged by how much it must separate itself from its surroundings.
* **Composition of Elements:** Whether the mark is typographic, symbolic, or a combination, and how its parts relate in scale, position, and hierarchy.
* **Isolation Strategy:** How the mark separates from the background and remains recognizable when reduced or viewed from a distance.

Any architecture that satisfies autonomy and recognizability is valid; the range is not limited to conventional lockup types.

### 3. Sub-Branding Hierarchy within the Logo
Organize the logo mark into two clear internal visual tiers:
1. **Primary Brand Wordmark:** Largest typographic scale, boldest weight, highest contrast color.
2. **Category Descriptor:** Clean, highly legible secondary text directly below or framed within the brand mark.

**Tagline / Quality Statement (independent element):** The tagline is not a fixed third tier of the mark. It is a supporting element whose placement is decided in Phase 3 by compositional balance. It may attach to the mark when the mark needs more weight or the format is compact; otherwise it is placed in another zone where it counterweights the mark and supports the hero.
