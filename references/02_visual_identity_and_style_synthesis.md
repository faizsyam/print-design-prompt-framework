# Visual Identity & Style Synthesis

*Used in Phase 2 of `SKILL.md`.*

This reference guide establishes the principles and systematic methods for selecting design movements, defining visual form language, orchestrating color systems, and architecting standalone brand marks without relying on static terminology banks or lookup tables.

---

## 1. Visual Movement & Style Selection Strategy

Rather than using generic aesthetic labels (*"modern," "trendy," "luxurious"*), visual style selection requires identifying an established design movement, visual tradition, or structural style defined by concrete, observable traits.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     DESIGN MOVEMENT & TRADITION                         │
│   (e.g., Swiss Style, Risograph Pop, Japanese-Nordic Editorial,         │
│    Artisan Woodcut, Technical Utilitarian, Industrial Brutalism)        │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
        ┌────────────────────────────┼────────────────────────────┐
        │                            │                            │
┌───────┴───────────────┐  ┌─────────┴───────────────┐  ┌─────────┴───────────────┐
│     FORM LANGUAGE     │  │  LINEWORK & RENDERING   │  │   SURFACE & TEXTURE     │
│ Geometric, Organic,   │  │ Flat vector, Cel-shaded,│  │ Risograph stipple,      │
│ Curved, Constructivist│  │ Etched lines, Borderless│  │ Matte paper, Halftone   │
└───────────────────────┘  └─────────────────────────┘  └─────────────────────────┘
```

### 1. Evaluating Design Movements
Identify a design movement based on the business's core positioning and operational context:
* **High-Speed Outdoor & Value Retail:** Benefit from movements emphasizing bold visual weight, flat planes, high contrast, and simplified visual forms (e.g., Pop Art, Retro Vector, Constructivist Poster, Swiss Utilitarian).
* **Craft, Culinary Heritage, & Artisanal Services:** Benefit from movements reflecting human touch, material tactile qualities, and historical continuity (e.g., Vintage Linocut/Etching, Heritage Editorial, Japanese Craft Aesthetics, Mid-Century Print).
* **Modern Services, Cafes, & Youth Brands:** Benefit from movements balancing minimalism with distinct character (e.g., Japandi Editorial, Modern Risograph, Neo-Brutalist Grid, Clean Geometric Vector).

### 2. Defining Observable Visual Characteristics
Once a movement is selected, articulate its execution through four concrete visual pillars:
1. **Form Language & Shape Vocabulary:** Specify boundary behaviors (e.g., sharp geometric angles, soft curvilinear arcs, asymmetrical block containers, organic freeform silhouettes).
2. **Linework & Edge Behavior:** Define line quality and stroke behavior (e.g., heavy dark outlines, borderless flat color planes, fine-line technical rules, hand-drawn brush edges).
3. **Rendering & Shading Technique:** Define how depth and surface are rendered (e.g., flat 2D vector fills, two-tone cel shading, cross-hatched linework, soft airbrush gradients, isometric dimensional projection).
4. **Texture & Print Material Fidelity:** Define paper and print characteristics (e.g., smooth matte vector finish, subtle risograph stipple grain, unbleached kraft paper fiber, offset halftone dots, foil stamp sheen).

## 2. Color System Architecture (60-30-10 Rule)

Color systems in print design must enforce structural readability, psychological alignment, and environmental contrast. Apply the **60-30-10 structural color ratio**:

```
+-------------------------------------------------------------------------+
|                                                                         |
|                       DOMINANT TONE (60%)                               |
|        Backgrounds, Large Surface Containers, Overall Base Atmosphere   |
|                                                                         |
|               +-----------------------------------------+               |
|               |                                         |               |
|               |       SECONDARY STRUCTURE (30%)         |               |
|               |  Text Blocks, Major Grid Lines, Framing |               |
|               |                                         |               |
|               |         +-----------------------+       |               |
|               |         | ACCENT / ACTION (10%) |       |               |
|               |         | Badges, CTAs, Hooks   |       |               |
|               |         +-----------------------+       |               |
|               +-----------------------------------------+               |
+-------------------------------------------------------------------------+
```

### 1. Structural Palette Allocation
* **Dominant Tone (60%):** Establishes the primary visual substrate and atmospheric baseline. Provides high contrast against both secondary copy elements and external ambient environments.
* **Secondary Structural Tone (30%):** Defines organizational grid containers, major visual framing, body typography, and structural graphic elements.
* **Accent / Action Tone (10%):** High-chroma, high-visibility color reserved strictly for high-priority focal points: starting price badges, emergency contact buttons, primary callouts, and key brand accents, as ranked by the Attention Hierarchy (`01`): accent follows the highest-priority elements, not a content category. Never dilute accent colors by using them in large background areas.

### 2. Contrast & Environmental Logic
* **Warm-Cool Balance:** Pair warm tones (reds, ambers, terracottas) to trigger appetite or energy with grounding cool or neutral tones (deep slate, navy, cream, forest green) for structural stability.
* **Print Chromaticity:** Account for substrate physics. Bright neon or digital light hues must be translated into saturated, printable print equivalents (e.g., deep cobalt, rich golden amber, vibrant emerald, rich terracotta).

## 3. Brand Mark Strategy & Visual Autonomy

The primary logo mark is the central anchor of brand identity. It must maintain **structural autonomy**—standing apart as a distinct visual asset while harmonizing with the overall print composition.

### 1. Autonomy & Independence Principle
* **Context Isolation:** The main logo mark must never depend on product illustrations, background photography, or seasonal props to be recognizable.
* **Iconographic Independence:** Avoid literal visual duplication between the logo and specific product offerings (e.g., a bakery logo should not simply be a picture of the exact bread listed on the menu). The logo represents the *institution*, not a single product variant.

### 2. Structural Mark Architectures
Structure the logo lockup based on brand tone and media requirements:
* **Enclosed Badge / Emblem:** Wordmark and symbol enclosed within a geometric container (circle, shield, arched frame, rounded rectangle). Highly effective for outdoor banners and busy street environments because it isolates the brand mark from background noise.
* **Integrated Wordmark & Symbol:** Custom display typography paired with a small, elevated icon (crown, botanical leaf, starburst, crest) placed above or beside the text.
* **Framed Ribbon / Banner Lockup:** Wordmark mounted over a ribbon graphic. The tagline joins this lockup only when the Sub-Branding rule below places it there.

### 3. Sub-Branding Hierarchy within the Logo
Organize the logo mark into two clear internal visual tiers:
1. **Primary Brand Wordmark:** Largest typographic scale, boldest weight, highest contrast color.
2. **Category Descriptor:** Clean, highly legible secondary text directly below or framed within the brand mark (e.g., *"Spesialis Ayam Bakar Solo"*).

**Tagline / Quality Statement (independent element):** The tagline is not a fixed third tier of the mark. It is a supporting element whose placement is decided in Phase 3 by compositional balance. It may attach to the mark (arching ribbon, pill container, or baseline frame) when the mark needs more weight or the format is compact; otherwise it is placed in another zone where it counterweights the mark and supports the hero.
